# 更新说明语言与子页下载入口

沿用 Sleepy Material Design 语义色与 Inter、系统中文字体。主色 #604BBF，主色容器 #E6DEFF，浅色背景 #FDF8FF，次级正文 #48454E，深色使用对应主题 token。下载按钮保持完整圆角与48像素触控高度，语言、主题、菜单各至少44像素。

位置和顺序不变量：

1. 所有非首页共13个路由的顶栏，从左到右为首页品牌入口、桌面导航、下载、语言、主题、手机菜单。无脚本时下载仍显示，滚动不隐藏。下载指向当前语言的下载页，下载页自身也保留该入口。
2. 手机端隐藏桌面文字导航，保持下载、语言、主题和菜单的顺序。380像素及以下用品牌图标保留首页入口和可访问名称，顶栏两侧使用8像素间距，为原生滚动条留出空间，避免压缩操作触控范围。首页维持原有 hero 互隐行为。
3. 更新说明依次显示页面标题与操作、当前语言目录、当前语言完整正文。桌面目录在左、正文在右；手机目录在正文前。切换语言使用现有顶栏语言链接，原始 release.json 不裁剪。

```text
桌面子页
[Sleepy] [功能 / 学校 / FAQ / 更新说明] [下载] [语言] [主题]

320像素子页
[品牌图标]                  [下载] [语言] [主题] [菜单]

更新说明
[标题、版本、日期与下载 / GitHub 操作]
[当前语言目录] [当前语言完整正文]
```

中文和英文源文档按发布 SOP 的两个一级标题选择，在构建时完成。代码围栏内的标题不作为语言分界。无法确认双语结构时停止构建，避免发布语言错误的内容。原始证据锚点与既有章节编号在各自语言页面保留，目录从选定语言正文生成。

完成条件是两语言正文与目录匹配、13个非首页顶栏在320至1440像素可见且可操作、串行检查和生产部署通过。契约在修改前的产物上出现15项预期失败，实施后重新构建验证。

| 用户原话 | 实现行为 |
| --- | --- |
| 界面是英文它就只显示英文，界面是中文就只显示中文 | 两个更新说明路由分别生成完整对应语言正文和目录，切换语言后显示另一份 |
| 所有非首页的页面，菜单栏它都得显示这个下载按钮 | 六类双语子页与404全部常驻顶栏下载入口，手机端不再隐藏 |
