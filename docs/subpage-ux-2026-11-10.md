# 子页面操作与视觉修订

本轮回应教务页密集、顶栏按压方角、首页下载去向和镜像入口不清楚的问题。逐页范围为中英文下载、学校、问答、开源、隐私、更新说明及 404；首页只修正两处 Android 下载去向及共用顶栏反馈，既有手机预览尺寸和页面段落保持。

采用 frontend-design、frontend-ui-engineering、web-design-guidelines、ui-ux-pro-max 与 designing-layouts 的适用规则。使用现有 Material 语义色：浅色主色 #604BBF、主容器 #E6DEFF、背景 #FDF8FF、次级正文 #48454E；深色沿用主题 token。Inter 和系统中文字体保持。按钮使用完整圆角，筛选和输入 16 像素圆角，主面板 28 像素圆角。结构由阅读顺序和留白区分，不靠每条信息加描边或阴影。

初次生产检查确认教务页同时显示 34 个地区按钮和 117 个协议按钮，桌面默认展开 33 组学校。这些内容遮住用户首先要做的校名检索。FAQ 54 个完整答案全部铺开，手机目录先于标题，查找成本高。下载页缺少来源选择，通用安装包与架构列表重复，校验入口的文字也与实际目标不符。顶栏文字链接没有圆角，叠色和浏览器点击高亮呈方形。

位置与顺序不变量：

1. 教务页先标题及用途，再校名搜索和地区选择，再折叠的协议筛选，再匹配结果。协议属于辅助条件，不能重新铺成按钮墙。初次最多展示 24 个学校结果，更多结果由明确的按钮继续显示；完整静态目录仍可在无脚本时读取。筛选写入 URL，浏览器回退恢复输入及结果，清空会同时清除全部条件。
2. 下载页先标题及正式版本，再 Android 来源选择，再通用包主操作和其他架构；旁边为 iOS 与网页入口，下方为安装、校验、架构说明和相关链接。镜像与 GitHub 选择始终有名称和域名。切换来源同步改变全部 APK 与校验文件，不重写发布信息或 GitHub 源码链接。中文默认镜像，英文默认 GitHub；两种来源始终可切换，无脚本时保留两套直链。
3. FAQ 先标题和检索，再目录与问题。答案使用可键盘操作的原生展开控件，正文完整保留；搜索匹配问题及答案，显示结果与可恢复空态；原有问题锚点可直接展开对应答案。
4. 长文页手机目录默认收起，标题始终在前；桌面继续左目录、右正文。政策、许可和发布说明原文不删改。所有顶栏点击背景、焦点及触屏反馈都沿控件圆角。

完成条件：所有子页面逐一进行手机和桌面、明暗主题视觉检查；搜索、筛选、回退、空态、答案展开、锚点、来源切换和下载文件完整性实际验证；串行类型检查、构建、测试通过后，按已有授权开 PR 合并并核验生产部署。

实际验证记录：类型检查零错误、零警告，保留两条既有提示；生产构建 15 页；串行测试 38 文件、520 项通过。8 项新旅程契约在修改前全部失败，修改后全部通过。学校保留 2881 个目录身份，FAQ 保留全部 54 问及原锚点。39 组额外的 320、768、1024 像素检查无横向溢出；中英文各子页面另有 402 与 1440 像素、明暗主题截图。镜像完整下载本次正式版的四个 APK 及校验清单，所有文件大小与 SHA-256 均与正式发布快照一致。

用户原话与实现行为核对：

| 用户要求 | 实现与验证 |
| --- | --- |
| 教务页面密集且难看 | 搜索在前，地区下拉，教务系统按需展开；默认 24 条分隔行，按批追加，结果与状态直接可见。实测搜索、地区组合、空态恢复与追加 48 条。 |
| 顶栏按压不能是正方形 | 导航链接及手机菜单均使用完整圆角；实际顶栏点击区域高度 44 像素、圆角 9999 像素，保留圆角叠色反馈。 |
| 首页下载 Android 跳下载页面 | 中英文首页的首屏与末段 Android 操作均进入对应语言下载页；已实际点击首屏验证。 |
| 直观提供 gh.qdp.qzz.io 镜像并保留 GitHub | 两个原生单选来源卡显示名称、域名与选中状态；全部 APK 和校验文件同步切源，发布与源码链接保留 GitHub。实测鼠标与键盘切换，完整文件回校。 |
| 检查每一个子页面 | 下载、教务、FAQ、许可、隐私、更新说明的中英文及 404 逐页检查。FAQ 新增全文搜索及原生答案展开，长文手机目录默认收起，正文保持完整。 |
| 手机预览只能等比缩放 | 继续保持内部 402 乘 874、屏幕比例 1206 比 2622；实际变换的横纵缩放系数相等。 |

构建和运行预览顺序：本机 Astro 的类型检查或构建会刷新 Vite SSR 依赖缓存，运行中的开发服务可能继续引用旧预打包文件。检查与构建后应重启后台服务；静态布局验收本轮使用正式构建产物单独预览，避免把开发缓存错误当作页面缺陷。
